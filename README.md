## ✨ Tính năng nổi bật

**🎨 Theme Switcher:** Tích hợp bảng chọn màu sắc tùy chỉnh (Đỏ mận, Xanh Navy, Xanh ngọc, Tím than) giúp cá nhân hóa trải nghiệm người xem.

**📱 Responsive Design:** Giao diện tương thích hoàn hảo trên cả thiết bị di động (Mobile), máy tính bảng (Tablet) và máy tính để bàn (Desktop).

**🖨️ Tối ưu In ấn (Print-friendly):** Bố cục tự động điều chỉnh và loại bỏ các nút chức năng thừa khi in ra PDF (Ctrl+P / Cmd+P), giữ nguyên cấu trúc 2 cột chuyên nghiệp.

**🎬 Hiệu ứng mượt mà:** Sử dụng Intersection Observer để tạo hiệu ứng xuất hiện (fade-in) mềm mại khi cuộn trang.

## 🛠️ Công nghệ sử dụng

- HTML5 & CSS3
- Tailwind CSS (thông qua CDN)
- Vanilla JavaScript (Xử lý DOM, Theme và Hiệu ứng)
- Google Fonts (Inter & Montserrat)
- FontAwesome 6 (Icon chuyên nghiệp)

## 🚀 Cách sử dụng

Clone repository này về máy:

```
git clone https://github.com/tandoancs/thao-ltd-porfolio.git
```
